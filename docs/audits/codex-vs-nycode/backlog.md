# Backlog Priorizado de Melhorias (`Codex -> nycode`)

Ordenação estrita conforme a regra de classificação: **todos os itens Classe A primeiro** (custo zero de tokens, sem alterar comportamento do modelo, prompt, esquema de ferramenta ou loop, sem binário nativo/Rust), seguidos pelos **itens Classe B ordenados pela razão Benefício / Custo** (todos condicionados a plano de eval pareado antes da adoção).

> [!NOTE]
> Itens classificados como **C** (16 áreas já cobertas, piores no custo x benefício, ou descontinuadas no próprio Codex) estão documentados em [rejeitados.md](rejeitados.md).
