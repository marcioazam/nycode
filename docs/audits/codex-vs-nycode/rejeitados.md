# Itens Rejeitados — Classe C (`16` áreas)

Registro de capacidades, formatos e subsistemas presentes no OpenAI Codex CLI (`rust-v0.172.0`, `~/source/codex-ref`) classificados como **Classe C** e descartados para adoção no `nycode` (`~/source/nycode-audit-codex`, `00fed2ae`), por serem **piores no custo x benefício**, **já cobertos melhor no `nycode`**, **específicos de nuvem/proprietário OpenAI** ou **descontinuados pelo próprio Codex**.

## Resumo dos Rejeitados (`C-01` a `C-16`)
